About CoolChain

CoolChain is an IoT-driven cold chain monitoring and analytics architecture engineered for end-to-end supply chain compliance. By decoupling physical device telemetry from cloud data analytics, CoolChain allows users to monitor any product profile (vaccines, biologics, blood, fresh produce, custom storage, etc.) with dynamic limit evaluation and statistical quality control — all running client-side with zero backend dependencies.

Analytical Formulations

  • Mean Kinetic Temperature (Haynes Equation): Evaluates non-linear accelerated chemical degradation using ΔH = 83.144 kJ/mol and R = 0.0083144 kJ/(mol·K).
  • Compliance Scoring: Evaluates time-in-range, excursion count and severity, grace period violations, and data completeness to produce a single 0-100 compliance score.
  • Dew Point (Magnus-Tetens): Computes surface condensation risks based on ambient temperature and relative humidity.

DHT11 Physical Hardware Capabilities & Limitations

  • Measuring Range: 0 °C to 50 °C (cannot measure frozen goods; use DS18B20 or PT100 for sub-zero).
  • Accuracy: ±2.0 °C temperature accuracy; ±5.0 % relative humidity accuracy.
  • Resolution: ~1.0 °C and ~1 % RH digital steps. Flatlining detection accounts for 1°C steps.
